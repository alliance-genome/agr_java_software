This file contains phenotype annotations from the Alliance gene_phenotype_annotation index. Each row represents a single phenotype annotation linking a genetic entity (gene, allele, or affected genomic model) to a phenotype term. Columns include the phenotype statement and its associated ontology terms, the genetic entity's primary identifier and symbol, the genetic entity type, experimental condition (when available), the data provider, and the supporting reference (PMID when available, otherwise the MOD curie). Per-MOD files split rows by data provider; the COMBINED file contains every row.
