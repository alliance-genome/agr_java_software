This file contains phenotype annotations from the Alliance gene_phenotype_annotation and allele_phenotype_annotation indexes. Each row represents a single phenotype annotation. The model, allele, and gene columns each name their own level of the annotation: the level matching the annotation's own subject is taken from that subject, the remaining levels from the inferred or asserted entities, and any level the annotation does not carry is left blank — so a gene annotation reports no model. The remaining columns are the taxon and species name, the phenotype statement and its associated ontology terms (when available), the experimental condition the phenotype was observed under (conditions related by has_condition or induced_by), the data provider, and the supporting reference (PMID when available, otherwise the MOD curie). Per-MOD files split rows by data provider; the COMBINED file contains every row.
