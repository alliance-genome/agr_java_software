This file contains one row per gene from the Alliance gene_summary index. Columns include the gene's primary identifier, symbol, full name, biotype (Sequence Ontology term), automated and MOD-provided descriptions, and the primary genome location (assembly, chromosome, start, end, strand). List-valued cells (synonyms, secondary IDs, cross references) are pipe-separated. Cross references include all linked external identifiers; the canonical UniProtKB Gene-Centric Reference Proteome (GCRP) entry, when present, is suffixed with " (GCRP)". Per-MOD files split rows by data provider; the COMBINED file contains every row.
